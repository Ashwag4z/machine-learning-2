
**** Dataset Description *****


The selected dataset is the Netflix Movies and Series dataset. It contains information about movies and TV shows available on Netflix, such as title, director, cast, country, release year, rating, duration, and other attributes.

**** Machine Learning Problem

This project is a classification problem. The goal is to predict whether a Netflix title is a Movie or a TV Show based on the available features in the dataset.

*** Target Variable

The target variable is `type`, which contains two main classes:

* Movie
* TV Show

*** Problem Statement

The objective is to use machine learning classification techniques to identify whether a Netflix title is a Movie or a TV Show based on its available attributes.
